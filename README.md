# Simple PvP Battleship Game 

> by Group 52 | CS111 Intro to Computing Prelims

The classic Battleship game is traditionally played using paper and pen. Players manually place their ships, choose their target positions, and keep track of the game on a grid. Our project aims to recreate this classic game as a digital version while maintaining its original concept and gameplay.

The digital version will allow players to enter their names, place their ships, select target positions, and take turns through a digital game interface.

**Published class site:** [https://annjoelle.github.io/battleship-pvp/](https://annjoelle.github.io/battleship-pvp/)
## 1. Problem Statement

The classic Battleship game is traditionally played using paper and pen. Players manually place their ships, choose their target positions, and keep track of the game on a grid. Our project aims to recreate this classic game as a digital version while maintaining its original concept and gameplay.

The digital version will allow players to enter their names, place their ships, select target positions, and take turns through a digital game interface.

## 2. Target Users

The target users of the Digital Battleship game are:

-   Students
    
-   Players who enjoy simple strategy games
    

## 3. IPO Chart

### INPUT

-   Player names
    
-   Ship positions
    
-   Target position
    

### PROCESS

1.  Enter the players' names.
    
2.  Place the ships on the grid.
    
3.  Confirm the ship placement.
    
4.  Select a target position.
    
5.  Check the selected target.
    
6.  Determine the result of the attack.
    
7.  Update the game board.
    
8.  Change the player's turn.
    
9.  Continue the game until a winner is determined.
    

### OUTPUT

-   Player names
    
-   Digital game grid
    
-   Ship positions
    
-   Attack result
    
-   Updated game board
    
-   Winner/game result
## 5. Interface Plan

The interface is planned around the main activities of the game:

**Player Name Entry**  
Players enter their names before starting the game.

**Ship Placement**  
Players use the game grid to select and place their ships.

**Target Selection**  
The current player selects a position on the opponent's grid as their target.

**Game Controls and Results**  
The interface provides controls for continuing the turn and displays the result of the player's action and the updated game state.

The interface is designed to be simple and easy to understand while maintaining the concept of the classic Battleship game.
